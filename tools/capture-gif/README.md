# 패치노트용 GIF 캡처

배포된 룰렛을 헤드리스 크롬으로 열어 **당첨 순간(폭죽 + 색종이)** 을 GIF로 만든다.
게시판에 올릴 패치노트 첨부용.

```bash
cd tools/capture-gif
npm install
npx playwright install chromium   # 최초 1회 (~130MB)
node capture.mjs celebration.gif
```

- 화면 전체(1280×1000 뷰포트)를 760×594로 담고, 당첨 직전 0.3초부터 2.2초를 캡처한다.
- 용량 목표는 **9MB**(네이버 카페 1장 10MB 제한 대비 여유). 색상 수 → 프레임 간격 순으로
  자동 조절해 목표 안에 맞춘다. 콘솔에 시도 내역이 찍힌다.
- 후보 메뉴는 스크립트 상단 `MENUS`에 들어 있다(도네로 만들어진 것처럼 추천자 닉네임 포함).
  배포본에는 디버그 훅이 없어 `localStorage`에 직접 심는 방식이다.
- `sample-0/1/2.png` 로 당첨 후 0.15·0.45·0.9초 시점 프레임이 함께 저장된다(확인용).

> 결과 GIF는 용량이 커서 저장소에 커밋하지 않는다(`.gitignore`). 필요할 때 다시 뽑아 쓴다.
